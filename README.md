# rth-rekreasi-pku
Website ini dirancang untuk mempermudah warga sekitar memanfaatkan taman hijau kota demi mendukung gaya hidup sehat. Melalui panduan fasilitas dan visualisasi suasana pagi hingga malam di RTH Putri Kaca Mayang, Taman Alam Mayang, dan Pedestrian Center, warga dapat dengan mudah merencanakan aktivitas olahraga maupun rekreasi harian.
